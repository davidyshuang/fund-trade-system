# 创意愿景（Idea）

> 文档编号：IDEA-001 ｜ 状态：已立项 ｜ 日期：2026-08-30

## 一句话愿景

> **让任何投资者都能在几分钟内完成一笔"合规、可追溯"的基金交易**——系统自动处理交易日历、截单时间、T+1 确认、资金冻结与份额登记，用户只需下单与查看。

## 目标用户

- **个人投资者**：需要申购/赎回基金、查询订单与持仓的客户
- **运营/管理人员**：维护基金产品、录入净值、管理交易日历的运营人员

## 核心痛点

1. 基金交易规则复杂（15:00 截单、T+1 确认、节假日顺延），人工容易算错
2. 申购/赎回涉及资金冻结与份额登记，需要严格的状态机与不变量守护
3. 跨系统协作（交易/资金/TA 账户/估值）需要解耦，避免互相直接调用

## 核心价值主张

| 价值 | 说明 |
| --- | --- |
| 规则自动合规 | 交易日历、截单、T+1 确认全部由领域层自动计算 |
| 资金安全 | 下单即冻结、确认才扣款、失败自动解冻，余额不足明确拦截 |
| 全程可追溯 | 每笔订单保留状态流转轨迹（下单→冻结→确认） |
| 架构可演进 | DDD 四层 + 领域事件解耦，可平滑对接真实清算系统 |

## 范围

**本期包含：** 申购、赎回、订单查询、持仓查询、管理端（产品/净值/交易日历/账户开立）、T+1 确认批处理。

**本期不包含：** 撤单、巨额赎回延期、外部支付渠道对接、风险等级匹配强校验（见 [BRD 待确认问题清单](02-brd.md#八待确认问题清单)）。

## 成功标准

- 20 个核心业务场景（GIVEN/WHEN/THEN）全部可通过自动化测试验证
- 完整交易闭环：下单 → 冻结 → T+1 确认 → 持仓/资金变动，端到端可演示
- 免费部署公网，任意设备可访问
