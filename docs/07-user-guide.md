# 使用指南（用户手册）

> 面向系统使用者（投资者 / 运营人员）的操作手册。系统在线地址见[部署指南](06-deployment.md)。

## 一、快速上手（3 分钟）

1. 打开前端页面（手机/电脑浏览器均可）
2. 右上角显示绿色「**后端已连接**」即系统就绪（首次访问如遇等待，是免费实例冷启动，30~60 秒）
3. 在「产品与申购」页选择基金 → 点「**申购**」→ 输入金额 → 确认

**演示账户**：客户 C001（初始资金 ¥20,000）｜ 客户 C002（初始资金 ¥50,000，API 可用）

## 二、功能操作说明

### 2.1 申购基金

1. 进入「**产品与申购**」Tab
2. 在"可申购产品"表格找到目标基金，点「**申购**」
3. 输入申购金额（**不得低于产品起购金额**，如 P001 起购 ¥1000）
4. 确认后系统自动：
   - 按交易日历 + 15:00 截单规则确定 **T 日**（15:00 前提交 → 当日 T；之后 → 下一交易日 T）
   - **冻结**申购资金（余额不足会明确提示）
5. 订单状态进入「资金已冻结」，等待 T+1 确认

> 💡 申购金额输入后如弹出"申购金额不能低于起购金额 1000.00"等提示，属业务规则拦截，按提示调整即可。

### 2.2 赎回基金

1. 进入「**产品与申购**」Tab，点「**赎回**」（需先有可用持仓）
2. 输入赎回份额（**不能超过可用份额**）
3. 确认后系统自动**冻结可用份额**，等待 T+1 确认
4. 确认成功后：份额扣减、赎回款入账（按持有天数计算赎回费，<7 天 1.5%）

### 2.3 查询订单

1. 进入「**订单查询**」Tab
2. 切换「申购订单 / 赎回订单」，支持分页浏览
3. 点订单行「**详情/轨迹**」查看完整信息 + **状态流转轨迹**（下单 → 冻结 → 确认）

**订单状态说明：**

| 状态 | 含义 |
| --- | --- |
| 待冻结（CREATED） | 已下单，等待资金/份额冻结 |
| 资金已冻结 / 份额已冻结 | 冻结成功，等待 T+1 确认 |
| 已确认（CONFIRMED） | 交易完成（份额/资金已入账） |
| 确认失败（CONFIRM_FAILED） | 确认失败，资金/份额已自动解冻退回 |

### 2.4 查看持仓与资金

进入「**持仓与资金**」Tab：
- **资金账户**：余额 / 冻结金额 / 可用金额
- **基金持仓**：总份额 / 冻结份额 / 可用份额

### 2.5 管理端（运营人员）

进入「**管理端**」Tab：
1. **① 发布净值**：选择产品、净值日期（T 日）、净值（4 位小数）→ 发布
2. **② 触发 T+1 确认**：选择 T 日 → 执行 → 查看申购/赎回确认成功失败笔数

> 流程：先为 T 日发布净值，再触发 T+1 确认，系统将确认该 T 日的全部待确认订单（份额入账、资金扣款/到账）。

## 三、业务规则速查

| 规则 | 说明 |
| --- | --- |
| 交易日 | 周末及法定节假日不交易，申请顺延至下一交易日 |
| 截单时间 | 交易日 **15:00**：前（含）提交 → 当日 T；后提交 → 下一交易日 T |
| T+1 确认 | 申购按确认净值算份额；赎回按确认净值算金额 |
| 申购费 | 外扣法：净申购金额 = 申购金额 ÷ (1 + 费率)（如 P001 费率 1%） |
| 赎回费梯度 | <7 天 1.5%；7~365 天 0.5%；366~730 天 0.25%；>730 天 0% |
| 资金冻结 | 申购下单即冻结；确认成功扣款；失败自动解冻 |
| 份额冻结 | 赎回下单即冻结可用份额；确认后扣减；失败解冻恢复 |

## 四、常见问题（FAQ）

**Q1：首次打开很慢 / 显示后端未连接？**
免费实例 15 分钟无访问会休眠，首次请求需冷启动 30~60 秒。刷新等待即可；也可先访问一次 `https://fund-trade-system.onrender.com/api/products` 唤醒后端。

**Q2：申购提示"资金不足"？**
演示账户 C001 初始 ¥20,000，会被测试消耗。可改用较小金额测试，或在 Neon SQL Editor 执行重置：
```sql
UPDATE funds_account SET balance='20000.00', frozen_amount='0.00' WHERE account_id='FA-C001';
```

**Q3：申购提示"申购金额不能低于起购金额"？**
产品有起购门槛（如 P001 为 ¥1000），输入金额需 ≥ 起购金额。

**Q4：为什么赎回费那么高？**
持有 <7 天赎回费率为 1.5%（惩罚短期频繁交易），长期持有费率递减，>730 天免费。

**Q5：数据安全吗？**
演示系统链接公开可访问，**请勿录入真实资金/隐私数据**。数据库为 Neon 云端 PG，多设备数据一致。

**Q6：订单一直"待确认"不处理？**
需要先在管理端为 T 日**发布净值**，再**触发 T+1 确认**，订单才会被确认。
